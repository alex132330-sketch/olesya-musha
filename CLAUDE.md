# Твой нутрициолог Олеся Муша

Сайт "Твой нутрициолог Олеся Муша". Тема: нутрициология, эфирные масла, здоровое питание.
Стиль: теплый, природный, женственный. Цвета: терракотовый, кремовый, бежевый.

## Стек

- **Next.js 14+ App Router** — маршрутизация и SSR
- **TypeScript** — типизация
- **Tailwind CSS v4** — стили (конфиг через CSS-переменные в `globals.css`)
- **shadcn/ui** — базовые UI-компоненты
- **lucide-react** — иконки
- **react-hook-form + zod** — формы и валидация
- **zustand** — состояние корзины

## Шрифты

- **Playfair Display** (`font-heading` / `var(--font-playfair)`) — заголовки
- **Inter** (`font-sans` / `var(--font-inter)`) — основной текст

## Структура проекта

```
/app          — страницы и маршруты (App Router)
/components   — переиспользуемые компоненты
  /ui         — shadcn/ui компоненты
/lib          — утилиты и конфигурации
/types        — TypeScript типы
/data         — моковые данные
/public
  /images     — изображения
```
